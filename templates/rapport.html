2. Introduction

Dans le cadre du Projet Intégrateur de première année à l’IFRI, notre équipe a développé une application web nommée IFRI MentorLink.

Cette plateforme permet de mettre en relation les étudiants souhaitant bénéficier ou offrir du mentorat académique et professionnel.

4. Description de la Solution

IFRI MentorLink est une application web permettant :

  • L'inscription des utilisateurs
  • La connexion sécurisée
  • La gestion des profils
  • La publication d'offres de mentorat
  • La recherche de mentors
  • Le système de matching
  • La messagerie instantanée

5. Technologies Utilisées

  • HTML5
  • CSS3
  • JavaScript
  • Python
  • Flask / Django
  • MySQL
  • Git & GitHub

9. Instructions de Déploiement

  1. Cloner le dépôt GitHub.
  2. Installer les dépendances Python.
  3. Créer la base de données MySQL.
  4. Importer le fichier SQL.
  5. Lancer le serveur.
  6. Accéder à l'application depuis un navigateur.

10. Manuel d'Utilisation

  1. Créer un compte.
  2. Compléter son profil.
  3. Ajouter ses compétences et lacunes.
  4. Rechercher un mentor ou mentoré.
  5. Consulter les résultats de matching.
  6. Communiquer via la messagerie.

Cette expérience a également renforcé nos compétences en collaboration, gestion de projet et résolution de problèmes.
